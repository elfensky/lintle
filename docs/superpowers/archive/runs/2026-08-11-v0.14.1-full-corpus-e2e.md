## The 5 hard suspects are upstream, not ours

All 5 `VRFY-EPOCH-CONFLICT` land in `tle2015`, indices 2,249,528–2,255,478, day 239
of 2015. The source itself carries two states under one element set:

```
1 11027U 78087A   15239.88831824  .00123286 -31983-7  89331-3 0  9747\
1 11027U 78087A   15239.88831824 +.00123286 -31984-7 +89331-3 0 0974\
```

Differing `n̈` (`-31983-7` vs `-31984-7`) in two space-track formattings. `clean`
keeps both, `verify` flags the contradiction rather than silently choosing, and
`dedup` then excludes them. The arithmetic closes exactly:

```
232,283,380 − 17,570,201 collapsed − 5 hard excluded = 214,713,174 written
```

That the count reconciles to the record is the proof the verify→dedup hand-off works.

## Findings

Three, none affecting correctness; filed as issues.

1. **`verify` prints no progress off a TTY.** `ProgressDisplay.file_ended` emits a
   `[n/29]` line when `not self._live_mode`; `UnitTable` prints the roster on
   `__enter__` and the results on `__exit__` with nothing between. A 2-hour
   `verify` under CI or `nohup` is therefore indistinguishable from a hang without
   `lsof`. `clean`'s off-TTY behaviour is the model to copy.
2. **`verify` is single-threaded** — 2 h 06 m against `clean`'s 21 m on 7 workers,
   so it is 64 % of the pipeline's wall clock. The grouping sort is the target.
3. **The `.broken.txt` sidecar embeds a wall-clock `generated:` stamp**, so it is
   not literally byte-reproducible across runs, while CLAUDE.md and ARCHITECTURE.md
   list the sidecar among the byte-deterministic artifacts. Either the invariant
   needs a "modulo run metadata" qualifier or the header should drop the stamp.
   (`report.json` carries a timestamp too, but by design as run metadata.)

## Verdict

The tool processed 30 GB three ways with no crash, no memory growth, no wrong
answer, and reproduced a prior version's output byte for byte. The remaining gap
before 1.0.0 is metadata: `Development Status :: 4 - Beta` and the `0.x` version
both understate what this run measured.
